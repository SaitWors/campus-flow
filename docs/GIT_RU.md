# История Git и дальнейшая разработка

В ZIP находится рабочий репозиторий `.git` с исходным коммитом серверной основы и последующими коммитами завершения приложения. В корне архива также находится `campus-flow-history.bundle` — переносимая копия истории.

Проверить в папке `campus-flow`:

```bash
git status
git log --oneline --all
```

Если распаковщик пропустил `.git`, восстановите репозиторий в новой папке рядом с bundle:

```bash
git clone campus-flow-history.bundle campus-flow-restored
```

ZIP собран из отслеживаемых исходников. В него не входят настоящие базы, локальная `.env`, зависимости, результаты разработки и резервные копии. После `npm ci` и Docker-сборки они создаются на вашей машине.

## Свой GitHub

Удалённый GitHub-репозиторий для этого проекта не создавался и push от вашего имени не выполнялся. Если хотите вести проект там:

1. На GitHub создайте пустой репозиторий, например `campus-flow`.
2. На первом шаге не добавляйте README, лицензию и `.gitignore`, поскольку здесь они уже подготовлены.
3. В папке локального проекта выполните, подставив своё имя пользователя:

```bash
git remote add origin https://github.com/YOUR_USERNAME/campus-flow.git
git push -u origin main
```

Если `origin` уже существует, сначала посмотрите `git remote -v` и убедитесь, что это нужный репозиторий. Не меняйте адрес вслепую. GitHub может попросить вход через установленный credential manager.

Вкладка **Actions** покажет workflow `Campus Flow verification`: тесты API/календаря и отдельно сборку Compose, сценарий PostgreSQL, резервное копирование и восстановление. Файл workflow добавлен; до push в ваш GitHub он там не запускался.

## Следующая доработка

```bash
git switch -c feature/my-change
```

Измените нужные файлы, запустите проверки из README, затем:

```bash
git add apps services scripts docs
git diff --cached
git commit -m "Describe the change"
git push -u origin feature/my-change
```

Коммитите также изменения compose.yaml, инфраструктуры и lock-файлов, если они относятся к работе. Перед публикацией проверьте состав diff. `.env`, базы и папка `backups` исключены из Git.

Версия 1.0.0 использует начальную схему базы. Следующие изменения моделей требуют миграции и отдельной проверки на копии данных; не редактируйте таблицы продакшена вручную без плана восстановления.
