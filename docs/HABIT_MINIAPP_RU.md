# Мандарин: личные профили и OPEN APP

Один Telegram-бот для владельца и приглашённых близких. У каждого свои привычки,
расписание, часовой пояс, XP, монеты, награды и история. Чужой прогресс не
показывается. Максимум 10 участников, включая владельца.

Mini App в чёрных и мандариново-оранжевых тонах открывается внутри Telegram.
Экраны: Сегодня, Прогресс, Награды, Настройки. Аккаунт Campus Flow приглашённым
не нужен: личность проверяется по подписанным данным Telegram.

## Обновление уже работающего бота

Нужны новые **web, API, Runner и образ бота**. Одного git pull или замены образа
бота недостаточно: старая web не знает путь Mini App, старая API не передаёт
HTTPS origin. Новый Runner сообщит об этом в ошибке запуска.

1. Получи `/backup` в чате прежнего бота. Это копия твоего личного профиля.
2. В Campus Flow останови карточку и дождись подтверждения Runner.
3. После merge дождись успешных **Campus Flow verification**,
   **Publish verified production images** и **Patchboard reminder bot**.
4. Обнови production Campus Flow штатно по
   [DEPLOY_TIMEWEB40_RU.md](DEPLOY_TIMEWEB40_RU.md), используя опубликованный
   SHA нового main. Сохрани текущие .env.production, пароли и тома.
   `APP_ORIGIN` — публичный HTTPS адрес сайта без пути и query.
5. Из обновлённого `/opt/campus-flow` перечитай Runner:

   ```bash
   bash scripts/install_bot_runner.sh start
   ```

6. В Summary успешного **Patchboard reminder bot** скопируй настоящий
   `ghcr.io/saitwors/campus-flow-habit-bot@sha256:…`. В **существующей** карточке
   поменяй образ и сохрани. Сохранение UUID сохраняет привязку тома.
7. Запусти бота и отправь `/app` в личном чате.

Существующий `/data/state.sqlite3` остаётся базой владельца. SQLite v2 обновится
до v3: баланс, настройки, уроки и награды сохраняются. Активированному владельцу
повторный `/claim` не нужен. До обновления можно использовать прежний образ.

## Как пригласить девушку

Владелец отправляет `/invite` боту или нажимает **Создать приглашение** в
настройках приложения. Передай ссылку девушке: она открывает её и нажимает
Start. Ссылка одноразовая, действует 24 часа.

У неё создаётся отдельный профиль. Стандартное движение включено, Java
выключена. Она может отключить движение, создать свои привычки, выбрать дни
недели и время, свои награды и часовой пояс. Твой Java-курс продолжится с
текущего занятия. Код владельца `/claim` для подключения гостей не используется.

Владелец может вызвать `/members` и `/revoke TELEGRAM_ID`. После отзыва доступа
участник не может войти в приложение или вызвать команды. Данные сохраняются:
повторное приглашение возвращает его профиль и настройки. Администратор
сервера с доступом к диску технически имеет доступ к SQLite-файлам.

## OPEN APP: меню чата и профиль

**В меню чата** бот сам задаёт кнопку OPEN APP при запуске. Есть также `/app`
и кнопка под сообщением с целями.

**В профиле бота** Main Mini App включается владельцем через BotFather:

1. `/mybots` → выбери бота → Bot Settings → Configure Mini App → Enable Mini App.
2. Укажи URL `https://АДРЕС-CAMPUS-FLOW/habits/UUID-БОТА/`.
   UUID: Campus Flow → карточка → Конфигурация → ID бота.
   Если поле ограничивает длину, можно убрать последний `/`: сервер
   перенаправит на полный адрес, сохранив параметры запуска Telegram.
   Например, для `mcg-mtuci.ru` адрес с UUID занимает 64 символа без `/`
   и 65 с ним. Это относится к полю URL приложения; short name — отдельное
   короткое имя, а не адрес сайта.
3. По желанию добавь иконку и описание в настройках Mini App.

Bot API не позволяет автоматически выполнить эту профильную настройку.
В обычном браузере доступен экран открытия через Telegram и демонстрация
интерфейса. Личные данные без подписанного входа не загружаются.
Через час закрой Mini App и открой заново: подпись входа имеет срок действия.

## Настройки и функции

- Личные привычки: название, описание, длительность 1–180 минут, время и дни
  недели; до 10 одновременно. Удаление отменяет ожидающие напоминания, история
  сохраняется. Для изменения личной привычки пока используются удаление и
  создание новой; редактирования на месте в этой версии нет.
- Java и стандартное движение включаются отдельно, прогресс не сбрасывается.
- Время 08:00–22:59 в своём часовом поясе. С 23:00 до 08:00 бот молчит.
- Таймер цели, напоминание через 30 минут, пропуск с подтверждением.
- Уровень, опыт, серия, последние 7 дней, достижения, история начислений.
- Личный магазин: добавить/удалить награду и подтвердить покупку. Повторное
  подтверждение не списывает монеты повторно. Реальных платежей нет.
- Пауза: на день в приложении, на 1–30 дней через `/pause 3`; вернуть `/resume`.

Выполнение подтверждаешь сам. Таймер не закрывает цель, Java-код автоматически
не проверяется. Нагрузка движения меняется со следующего дня.

```text
/app
/invite
/join КОД
/habit Читать | 15 | 18:00
/habitdel ID
/enable code off
/enable sport on
/time code 19:00
/tz Europe/Moscow
/today
/profile
/shop
/backup
```

Курс: `/course`, полная заметка: `/lesson`. `/course start 2` нужна только если
первый урок сделан до первого зачёта в боте.

## Копии и восстановление

Все файлы в прежнем томе `cfbot-data-<UUID>`:

```text
/data/state.sqlite3                      профиль владельца
/data/members.sqlite3                    участники и хеши приглашений
/data/users/<telegram_id>/state.sqlite3   профили приглашённых
```

`/backup` содержит только профиль отправителя. Восстановление личной базы:
[HABIT_BOT_RU.md](HABIT_BOT_RU.md). Копию приглашённого нельзя восстанавливать
вместо базы владельца. Для полного восстановления нужны **все файлы тома**,
включая members.sqlite3 и users/. Сначала останови бота через панель и дождись
остановки, затем делай полную копию тома штатным инструментом Docker.
Не копируй один .sqlite3 из работающего WAL-каталога. Владельцы файлов после
восстановления — 10001:10001. Том бота не входит в backup PostgreSQL Campus Flow.

При откате образа v3 → v2 прежний бот не откроет новую схему. Нужна копия v2,
сделанная до обновления; текущие данные v3 сохрани отдельно.

## Техническая проверка

Web подключён к выделенной сети campus-flow-habits. Runner подключает к ней
только Telegram-образы с метками com.campus-flow.bot.storage=data-v1 и
com.campus-flow.bot.miniapp=habits-v1. API слушает 8081 внутри сети, без host port.
HTML/JS/CSS входят в доверенный образ web. Прокси ограничен UUID и JSON routes,
не передаёт cookies и внутренние токены сайта; отсекает Set-Cookie и X-Accel,
задаёт JSON MIME, nosniff и sandbox CSP для ответов бота.

CI запускает настоящий Nginx, API из образа (UID 10001, read-only, 192 MiB) и
Playwright: два профиля, цели, таймер, награда, настройки, отсутствие входа и
узкие экраны. Проверяются также вредоносный upstream HTML, cookies и X-Accel.
Скриншоты: Actions artifact **habits-miniapp-screenshots**.
