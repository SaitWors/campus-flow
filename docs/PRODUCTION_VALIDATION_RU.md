# Проверка production-профиля

Текущая версия использует **пять контейнеров**: web, auth, schedule, notifications, PostgreSQL. Базы и роли разделены. Сумма установленных лимитов RAM — **1024 МиБ**; это потолок конфигурации, а не измерение потребления на реальном сервере.

| Контейнер | Лимит RAM, МиБ |
| --- | ---: |
| PostgreSQL | 384 |
| auth | 160 |
| schedule | 224 |
| notifications | 192 |
| web | 64 |

`scripts/verify_production.py` выполняется только в одноразовой GitHub Actions установке. Он проверяет:

- перенос реальных данных прежней версии из отдельных БД, точное сравнение дампов до миграций, сохранение занятий и старой сессии, повторный старт миграций;
- новую установку, реальные HTTP-сценарии ролей, расписания, предметов, работ, приватных статусов, уведомлений, вопросов, материалов и MFA;
- параметры PostgreSQL, реальные пулы, изоляцию DB-ролей, healthchecks, лимиты, перезапуски и OOM;
- интерфейс, мобильную ширину, публичную офлайн-копию;
- SHA-256 материалов, восстановление во временных базах и отдельном файловом каталоге, восстановление после удаления одноразовых схем и файлов, операторский restore с предварительной полной копией, перенос источника с файлами и прежнего источника без тома;
- отказ несовместимому прежнему образу до изменения данных и повторное развёртывание текущего образа.

Новый CI не утверждает совместимость отката на старые схемы и не использует прежние замеры шестиконтейнерной версии как результаты этой версии.

Локальная проверка в среде разработки охватывает Python/SQLite, реальный HTTP между API, frontend unit tests и production-сборку: 102 Python-теста, 21 frontend-тест. Начальный JS уменьшился с 388,87 до 325,86 кБ. Docker в этой среде отсутствует: PostgreSQL, лимиты контейнеров и сам production-сценарий требуют зелёного CI. Telegram-транспорт проверяется тестовым сервером/подменой транспорта; реальные отправки требуют настроенного бота. SSH-копирование проверяется архивами и контролируемым транспортом, без доступа к внешнему хранилищу пользователя.

На реальной VM Timeweb 2 ГБ профиль пока не проверен. После установки используйте [инструкцию диагностики](DEPLOY_TIMEWEB40_RU.md) и наблюдайте память/диск/задержки под нагрузкой.

Материалы добавляют приватный том, а не новый сервис. Локальные operations-тесты проверяют traversal/ссылки/дубликаты, повреждение архива и файлов, обязательный архив для схемы 5, поддержку старых копий, порядок валидации до изменений назначения, staged-roundtrip и сохранение прежних файлов при ошибке импорта/публикации. CI дополнен API и browser-сценариями материалов во всех профилях, включая потоковую загрузку 50 МиБ под production-лимитами. Настройка gateway и Windows PowerShell-потоки требуют проверки соответствующей среды: локально Docker/Nginx/PowerShell отсутствуют.
