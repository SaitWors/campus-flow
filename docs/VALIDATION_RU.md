# Проверки

Запускайте изменяющие данные сценарии только на новых одноразовых установках. `smoke.py` отказывается работать с уже настроенным экземпляром.

```bash
.venv/bin/python -m pytest -q
cd apps/web
npm test
npm run build
```

Python-проверки включают реальные HTTP-процессы API, роли/CSRF, конфликт версий, права на подгруппы, приватные статусы работ, безопасные ссылки, миграции, расписание/календарь/переводы, MFA, личные вопросы, уведомления, Telegram-привязку/повторы, архивы и защиту операций восстановления. Frontend-проверки проверяют даты/темы, сохранённые фильтры, ближайшую пару и перевод локального срока в UTC.

CI дополнительно запускает Compose/PostgreSQL, проверяет переводчик и режим без него, браузерные сценарии, согласованный backup/restore и отдельный production-профиль. Браузерные проверки: темы, мобильная ширина, каталог/предпросмотр, MFA, гостевой доступ, вопросы, уведомления, Сегодня/Работы/Предметы, личный статус, сохранённые фильтры.

Системы записи на сдачу больше нет. Старая точка API отвечает 404; её поля не принимаются в новых шаблонах. Импорт расписания исключён из этой версии.

[Ограничения production-проверки](PRODUCTION_VALIDATION_RU.md). Реальный Telegram и внешний SSH-хост подключает владелец; тесты не отправляют сообщения одногруппникам.

## Локальный результат этой версии, 6 октября 2026

- Python: `102 passed` (предупреждения устаревших API зависимостей сохранены).
- Frontend: `21 passed`; `tsc -b && vite build` завершились успешно.
- Начальный JS: 388,87 → 325,86 кБ, gzip 119,38 → 102,45 кБ. Это сравнение production-сборок, не замер времени загрузки или всей памяти браузера. CSS вырос с появлением новых экранов.
- Оба Compose и CI YAML проверены строгим парсером без повторов ключей; зависимости ссылаются на существующие сервисы. `git diff --check` чистый.
- Отдельное ревью подтвердило защиту приватных статусов, текущей подгруппы уведомлений и восстановления после ошибки переноса.

Локальный браузер использует Chromium headless shell и тестовый HTTP-шлюз со сборкой приложения. Полный Chrome не запускается из-за запрета Unix-сокетов среды; проверка жизненного цикла системного Web Push остаётся в CI на полном Chromium. Режим `CAMPUS_UI_ONLY=1` явно исключает только этот блок, а обычный CI выполняет весь сценарий. Docker/PostgreSQL, SSH-хранилище владельца и реальные Telegram-отправки локально не проверены.
