# Проверки версии 1.0.0

Финальная проверка исходников: 14 сентября 2026 года. Это описание фактически выполненных проверок, а не гарантия отсутствия всех ошибок.

## Выполнено

| Проверка | Результат |
| --- | --- |
| Python: `python -m pytest -q -s` | Сквозной сценарий трёх самостоятельных HTTP-сервисов прошёл |
| Регистрация и доступ | Первый администратор, одноразовость настройки, приглашения, лимит регистраций, ожидание подтверждения, роли, защита от повышения роли заместителем |
| Безопасность запросов | Отклонение неавторизованного доступа, неверного CSRF и постороннего Origin |
| Расписание | Настройка семестра, смена чётности через неделю, запрет пересечений, откат конфликтующей записи, отклонение устаревшей версии |
| Конкурентная очередь | Два параллельных запроса одного студента; два разных студента на последнее место; правильный порядок после повторной записи |
| Повтор запросов | Повтор ранее выполненной записи после выхода не возвращает студента в очередь |
| Управление очередью | Вызов первого, запрет второго одновременного вызова, пауза, завершение, отсутствие, повторная запись после отсутствия |
| Изменения пары | Перенос сохраняет очередь и места; требуется повторное открытие; отмена закрывает активные места; истёкшее занятие закрывает очередь |
| Экспорт и журнал | iCalendar с отменами и английскими названиями, перенос строк по 75 байт, журналы auth/schedule/queue, события расписания |
| Учётные записи | Одноразовый код сброса, отзыв сеансов после сброса и блокировки |
| Vitest | 6 тестов календаря: понедельник/воскресенье, чётность, предшествующие недели, сетка месяца, январь→февраль, границы года и високосная дата |
| Frontend build | TypeScript-проверка и production-сборка Vite прошли |
| Браузер | Открытие формы настройки, неделя с примерами, создание очереди, смена темы, месяц, английский язык и список участников |
| Адаптация | Проверен экран шириной 390 px, отсутствие горизонтального переполнения страницы; исправлено пересечение названий дней с карточками |
| Консоль браузера | В проверенном пользовательском сценарии ошибок JavaScript не возникло |
| Конфигурационные файлы | YAML Compose разобран, проверено наличие семи сервисов; Bash-скрипты прошли `bash -n` |

HTTP-проверка запускала три отдельных процесса Uvicorn и три временные SQLite-базы, не подменяя сетевое взаимодействие между сервисами. Для сценариев гонок использовались параллельные HTTP-запросы. Проверки выполнялись на тестовых аккаунтах, без реальных данных группы.

Браузерная проверка использовала локальный Chromium и действующие HTTP API с временными данными. На снимках в [screenshots/](screenshots/) — демонстрационное расписание, а не настоящие пары БВТ2302. Форма первого запуска проверена на отображение; создание тестового сеанса для визуальных проверок выполнялось через API.

## Что здесь не запускалось

**Docker CLI / daemon в среде отсутствовали.** Поэтому здесь не выполнены Docker-сборка, фактический запуск контейнеров, проверка PostgreSQL-блокировок, Nginx внутри контейнера и круг backup→restore. Структурная проверка YAML не заменяет `docker compose config` и реальный запуск.

Для этого добавлен `.github/workflows/ci.yml`. Его отдельный job:

1. Собирает и запускает все семь контейнеров с проверками готовности.
2. Прогоняет тот же HTTP-сценарий через Nginx с настоящими PostgreSQL-базами.
3. Проверяет схемы OpenAPI и недоступность внутренних маршрутов.
4. Делает резервную копию, восстанавливает её и проверяет аккаунты, расписание и журнал очередей.

Workflow ещё не запускался в GitHub: удалённый репозиторий не создавался. До использования реальных данных нужно получить зелёный результат этого job или повторить соответствующую проверку на тестовом Docker-хосте.

PowerShell-скрипты не выполнялись под Windows в этой среде. Бинарные дампы в них переносятся через `docker compose cp`, чтобы не зависеть от перенаправления бинарного вывода в Windows PowerShell 5.

Нагрузочный тест на сотни/тысячи пользователей, проверка всех мобильных браузеров, внешний аудит безопасности, SSO, Telegram и отправка писем не входят в выполненную проверку. Приложение рассчитано на одну учебную группу.
