# Patchboard reminder — реализация

Основа: main после PR9, 915f287fc61e97b92be86b3d4529e43b7f485fb5.
Код бота автономен в bots/mandarin-habits, зависимости отдельные от Campus Flow.
30 заметок и структурированные цели импортированы из переданного архива Java;
сам архив и код учебного Patchboard не изменены.

SQLite v2 содержит номер урока в цели и уникальные зачёты занятий. Тема выбирается
по незавершённым занятиям, а не дате. Монеты за один урок начисляются один раз.
Остаются ежедневные цели движения, транзакции, награды и резервирование.
Код активации — 128 бит HMAC-SHA256 от BOT_TOKEN. Токен не сохраняется в SQLite.

Runner поддерживает опциональный контракт com.campus-flow.bot.storage=data-v1:
один фиксированный local-volume по UUID, только /data, BOT_DATA_DIR=/data.
Коллизии меток, чужие UUID и driver Options, в том числе bind, отклоняются.
UID10001, read-only rootfs, CPU/RAM, секретный envfile и прочая изоляция сохранены.
Образы без метки работают как прежде. Контейнер удаляется отдельно от тома.

Workflow Patchboard reminder bot проверяет код/образ в PR, публикует только main,
сохраняет уже опубликованные commit-теги и выводит готовый image@digest в Summary.
Публичность GHCR-пакета проверяет владелец при первой публикации.

Проверка: отдельные unittest бота, новые Runner pytest, существующий backend-suite,
Vitest и production build. Docker Engine в среде отсутствует; реальный образ,
mount, публикация GHCR и доставка Telegram проверяются CI/на VPS. Digest нельзя
считать готовым до успешной публикации. VPS в этой сессии не изменялся.
